# Agile SciTech website — design options

`DESIGN.md` describes the design the site uses today. This file lists other directions you could choose instead. Nothing here is applied. Tell me a code (for example "P2 + T1") and I will apply it across the site.

## 6. Overall style directions

Bigger changes that touch every page.

| Code | Name | What changes |
|---|---|---|
| **S0** | Light and minimal (current) | Pale surfaces, soft shadows, rounded cards |
| S1 | Flat | No shadows, 1px borders only, 12px corners. Even simpler and faster to scan |
| S2 | Bold blue | Solid brand-blue page tops and bands, white cards on top. Stronger brand presence |
| S3 | Editorial | Serif headings, wide margins, larger photos, fewer cards |
| S4 | Dark | Navy background with light text throughout. Striking, but harder to read product detail |
| S5 | Glass | Frosted translucent cards over photos, as on the home contact form |
