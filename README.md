# Agile SciTech website

Static homepage for Agile SciTech — plain HTML, CSS and JavaScript, no build step.

## Files

- `index.html` – page markup
- `styles.css` – all styling, including tablet and phone layouts
- `script.js` – category tabs, card carousels, mobile menu, scroll effects
- `images/` – logo, partner logos, product photos and section photos

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

## Publish with GitHub Pages

In the repository on GitHub: Settings → Pages → Source "Deploy from a branch" → branch `main`, folder `/ (root)`.

## Hero options

`hero-options.html` shows nine alternative hero designs for comparison. Switch with the bar at the bottom or the left/right arrow keys. Its styles are in `hero-options.css`.
